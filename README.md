# Mia Chen — Illustrator Portfolio

## Overview

A fictional, single-page portfolio concept for illustrator and visual storyteller Mia Chen. The site uses a modern, minimalist layout, warm neutral backgrounds, generous spacing, and colorful artwork placeholders.

## Design Direction

- **Mood:** Thoughtful, creative, and professional
- **Background:** Warm white (`#F8F5EF`)
- **Text:** Charcoal (`#302F2B`)
- **Accent:** Terracotta (`#D96C4F`)
- **Surface:** Warm beige (`#E8E1D6`)
- **Headings:** Georgia, serif
- **Body and navigation:** Arial, sans-serif

## Tech Stack

- HTML for page structure
- CSS for styling, responsive layouts, and temporary artwork compositions
- JavaScript file included for future use; the current page does not require interactive JavaScript

## Website Sections

1. Navigation
2. Hero
3. Selected Works
4. About
5. Services
6. Contact
7. Footer

The layout adapts across desktop, tablet, and mobile screen widths.
